Digital Notes Management System

A simple Python-based Digital Notes Management System that allows users to create, view, search, edit, and delete notes. The project uses file handling to store notes permanently in a text file.

Project Information

Detail| Description
Project Name| Digital Notes Management System

Programming Language| Python 3

Objectives

- To create and manage digital notes.
- To add, view, search, edit, and delete notes.
- To store notes permanently using file handling.
- To provide a simple and user-friendly system.

Features

- Add Notes: Create new notes with a unique ID.
- View Notes: Display all saved notes.
- Search Notes: Search notes by title or content.
- Edit Notes: Update existing notes.
- Delete Notes: Remove unwanted notes.
- File Storage: Save notes in "notes.txt".

Technologies Used

- Python 3
- File Handling
- Text File ("notes.txt")
- Visual Studio Code

How to Run the Project

1. Download or clone the repository.
2. Open the "01_Source_Code" folder.
3. Run the Python file:

python digital_notes.py

4. Select an option from the menu.
5. Manage your notes.

File Storage Format

All notes are stored in "notes.txt" using this format:

Note_ID|Title|Content

Example:

N1|Python|Learn loops and functions
N2|Maths|Revise calculus
N3|DBMS|Study functional dependency

Main Menu

1. Add Note
2. View Notes
3. Search Note
4. Edit Note
5. Delete Note
6. Exit

Advantages

- Easy to use.
- Saves notes permanently.
- Reduces manual record keeping.
- Supports editing and deleting notes.
- Simple and lightweight application.

Conclusion

The Digital Notes Management System is a simple Python project that helps users manage their notes digitally. It demonstrates the use of Python functions, conditional statements, loops, and file handling. The project provides an easy way to store, search, update, and delete notes.
